# 08 · 提示词系统

> 定义每次生成正文的提示词组装规范。
> 版本：1.0 ｜ 依赖：`02`、`04` ｜ 相关：`07`(审计)、`09`(技能)

---

## 1. 五层提示词架构

```
Layer 1: System Prompt（不变层）— 作家身份 + 叙事宪法 + 反AI味协议
Layer 2: Context Injection（动态层）— 大纲 + 真相文件切片 + 前情摘要
Layer 3: User Prompt（每章动态）— 章纲 + 节拍 + 即时校验指令
Layer 4: Skill Injection（有激活技能时）— 技能指令 + 示例
Layer 5: Audit Injection（审计阶段独立注入）— 审计规则 + 确定性线索 + 技能rules
```

## 2. Layer 1 — 作家身份锚点

```
你是一位经验丰富的长篇小说创作者，精通类型文学叙事技法。你的创作原则：
1. 信息密度优先：每段推进剧情/角色/悬念/信息差，"什么都没发生的段落直接删掉"
2. 感官先行：先感官→再动作→后对话，禁止跳过感官直写情绪标签
3. 角色差异：反应=背景×身体状态×利益关系，没有两个角色用同一种方式恐惧
4. 因果严锁：一切转折对应前文细节，禁止"突然/意外/不知为何"
5. 留白信任读者：不解释角色为什么这么做，用行为展示动机
```

## 3. Layer 1 — 叙事宪法（全局不可变）

要点：**FACT_LOCK**（标 [FACT_LOCK] 的不可违背；角色认知边界 front 只写 knows+partial）；**关系锁定**（social 卡 actual 是客观事实，按视角注入 subjective，不越界）；**伏笔纪律**（生成阶段不自行造新伏笔，偷换靠铺垫，渐进揭示不超额，种子词符合当前阶段）；**禁止事项**（不私创未登记角色、禁用上帝视角、禁段尾哲学总结、禁开头介绍背景）；**章节连贯性**（小说是连贯故事而非分集，开头延续上章余韵，结尾悬在"未完成"）；**解释句式禁令**（禁"不是A而是B""A——是B""与其说A不如说B"）。

## 4. Layer 1 — 反AI味协议 P1-P8

核心是把"什么是好小说"编译成可执行法则（详见 `07` 的 P1-P8）。P6（解释句式）所有强度下均 zero-tolerant；P5 在战斗章弱化；P1 在文艺段落弱化。

## 5. 反AI味强度参数化（P1-P8 按章节类型动态配置）

| 强度 | 含义 | 执行方式 | 审计 | 适用 |
|------|------|---------|------|------|
| subtle | 弱约束 | 建议提及 | 仅标记 | 文艺段落/日常/呼吸空间 |
| moderate | 中等 | 明确要求+1示例 | 标记并修订 | 常规叙事/对话/探索 |
| strong | 强约束 | 强制执行+2示例 | 不通过打回 | 战斗/转折/高潮/伏笔交汇 |

**按章节类型默认配置**：战斗章↔strong；对话/探索↔moderate；日常/文艺↔subtle；转折↔strong。（具体映射表见 `07`）

## 6. Layer 2 — 上下文注入

```
## 当前卷纲 / 幕纲 / 章纲 / 场景纲 （按 reveal_density 过滤）
## 六系统状态切片（按上下文预算注入）
  ### 人物卡切片（出场角色完整卡，认知边界过滤仅 knows+partial）
  ### 社会关系卡切片（按视角注入 subjective，不注入 actual_type）
  ### 势力卡切片（普通角色 public_status，间谍/高层 actual_status）
  ### 地理卡切片（场景卡 + 相关旅行矩阵）
  ### 时间锚点（当前锚点 + 视角角色 time_perception）
  ### 伏笔/支线状态切片（需操作的伏笔 + converging/progressing）
## 前情摘要（前3-5章摘要，经 `05` 检索协议拉取相关记忆）
```

## 7. Layer 3 — 任务级指令

```
## 当前章节任务
## 章纲（六维度：梗概/角色行为/氛围/冲突/叙事目标/类型）
## 视角序列（单视角或多视角认知边界切片；多视角不互相矛盾）
## 节拍分解（Scene & Sequel）
## 即时校验指令（一致性硬约束：新事物须有伏笔；认知边界；旅行时间；关系 subjective；伏笔交汇）
## 概念播种指令（种子词当前阶段 + 使用方式，不提前偷换）
## 揭示链状态（当前步/总步数；揭示节点可揭内容 / 非揭示节点 NO_REVEAL）
## 激活技能 / 字数目标
```

## 8. Layer 4 — 技能注入

```
# 激活技能
## 技能N：{prompt_directive} + 示例（输入/输出）
（最多5个，总 token 预算 5000；rules 不注入生成，只进 Layer5 审计）
```

## 9. Layer 5 — 审计注入

```
# 审计任务
## 确定性检查结果（作为线索）：角色/地点/势力提及比对、共指、关系抽取、情感、句长、感官、过渡词、解释句式、章节连贯性
## 审计维度清单（P/C/I/L/S/A + 判定标准）
## 真相文件片段 / 待审计内容（正文）
## 输出要求：每维 pass/fail；严重度标注；问题清单排序；综合评分；结论；回炉建议
```

> 结构性检查结果仅是线索，需结合上下文做最终判定；存疑项由独立 audit_model 复核（见 `07`）。
