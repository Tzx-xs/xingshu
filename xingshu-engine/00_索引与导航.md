## 1. 用途

原始蓝图是一份约 2200 行的单文件。为避免开发时反复读取长文、且便于按模块迭代，现将内容**按板块拆分**为多个独立文件。每个板块文件聚焦一个职责边界，可独立阅读、独立演进、按需引用。

**读取路径建议**（按需打开，不必全部通读）：

| 使用场景       | 优先读取文件                              |
| ---------- | ----------------------------------- |
| 想快速了解整体    | `00_索引与导航.md` + `01_架构总览.md`        |
| 实现生成主循环    | `02_创作管线流水线.md` + `08_提示词系统.md`     |
| 实现事实库/一致性  | `04_真相文件-事实库.md` + `05_记忆与状态管理.md`  |
| 实现审计       | `07_审计与质量系统.md` + `11_质量报告与全量校验.md` |
| 实现用户技能     | `09_技能系统.md`                        |
| 实现编辑/暂停/回滚 | `10_状态机与编辑回滚.md`                    |
| 实现存储/目录/预算 | `12_文件系统与工程实现.md`                   |
| 实现测试       | `13_沙箱与测试规范.md`                     |
| 排期         | `14_项目实施路线图.md`                     |

## 3. 借鉴来源汇总（精华出处）

本优化版吸收以下开源项目/方案的思想，具体借鉴点已在各板块文件中以「精华借鉴」标注：

| 方向  | 项目                  | 借鉴点                                                                         |
| --- | ------------------- | --------------------------------------------------------------------------- |
| 记忆  | Mem0                | ADD-only 只累积不覆盖；多信号检索（语义+关键词+实体）；事实累积可追踪                                    |
| 记忆  | Graphiti            | 显式时效窗口（valid\_from/valid\_until）；Episodes 溯源链                               |
| 记忆  | Cognee              | remember / recall / forget / improve 四段操作 API；会话缓存+长期图谱分离                   |
| 记忆  | Zep                 | 异步事实抽取，不阻塞主循环                                                               |
| 一致性 | LangGraph           | 每步 Checkpoint；时间旅行；Fork 分支探索；Human-in-the-loop 暂停恢复                         |
| 一致性 | Novel-OS            | 确定性 Continuity Engine 先检 + LLM 兜底；StoryState 结构化；"This is intentional" 作者声明 |
| 评测  | NovelForge          | Planner/Characters/Writer/Reviewer 场景职责分离；LLM-as-Judge 打分                   |
| 工作流 | OpenNovel           | LangGraph 多 Agent 流水线编排                                                     |
| 工作流 | ScrollWeaver / CoDi | Director-Actor 分层叙事调度（高层控制 + 角色执行）                                          |
| 记忆  | AI\_NovelGenerator  | 章节摘要 + 向量检索作为低 token 长期记忆                                                   |
| 上下文 | ContextCraft        | 压缩后语义覆盖率校验；压缩版本回滚                                                           |
| 上下文 | LongWriter          | 子任务拆解；超长生成目标                                                                |
| 记忆  | OpenTheatre         | 层级检索式记忆（Working/Episodic/Semantic）                                          |

> 出处为公开 GitHub 仓库：`mem0ai/mem0`、`getzep/graphiti`、`topoteretes/cognee`、`getzep/zep`、`langchain-ai/langgraph`、`mrigankad/Novel-OS`、`RhythmicWave/NovelForge`、`Cppys/OpenNovel`、`siruizou2005/ScrollWeaver`、`Speeditidious/CoDi`、`YILING0013/AI_NovelGenerator`、`Siddhant-K-code/contextlab`、`dakshjain-1616/ContextCraft`、`THUDM/LongWriter`、`johnnie193/Open-Theatre`。
