## 1. 技能库目录结构

```
skill_library/
├── builtin/          # 预置技能 skill_pacing_control.yaml ...
├── user/             # 用户自定义技能
├── novels/{novel-id}/ # 小说专属技能
└── _meta/
    ├── conflict_matrix.json
    └── index.json
```

## 2. 技能定义格式

```yaml
skill:
  id: skill_001
  name: "环境暗示法"
  category: narrative_technique   # 8分类见下
  description: "..."
  author: user                    # user / builtin / imported
  version: "1.0"
  trigger:
    type: manual                  # manual / auto / conditional
    auto_match_conditions:
      - scene_type: "自然环境"
      - character_state: ["焦虑","紧张"]
  content:
    prompt_directive: |           # ≤300 tokens，注入 Layer4
    examples:                     # ≤3个，每个≤150 tokens
      - input / output
    rules:                        # 确定性检查，注入审计层，零 token 成本
      - id / text / check_type(semantic,regex,count,distribution) / params
  parameters:
    intensity: subtle             # subtle/moderate/strong
    scope: paragraph              # word/sentence/paragraph/scene/chapter
  injection_points: [planning, generation, audit, revision]
  applicable_genres: ["玄幻","仙侠","文学","言情"]
  applicable_phases: [generation, revision]
  requires: [characters]          # 依赖的真相文件类型
```

## 3. 技能 8 分类

| 分类值 | 中文 | 说明 | 典型注入点 |
|--------|------|------|-----------|
| narrative_technique | 叙事技巧 | 视角/倒叙/意识流等 | generation, revision |
| style_template | 文风模板 | 用词/句式/意象体系 | generation |
| plot_device | 情节装置 | 误会/巧合/反转/悬念 | planning, generation |
| character_method | 角色塑造法 | 性格展示/成长弧/动机 | generation, revision |
| dialogue_technique | 对话技巧 | 潜台词/话轮/性格化语言 | generation, audit |
| pacing_control | 节奏控制 | 句长/段落密度/张力 | generation, audit |
| worldbuilding | 世界观构建 | 设定展示/信息嵌入 | planning, generation |
| revision_method | 修订方法 | 回炉方向/删减/增补 | revision |

## 4. 技能消费规则

1. 同时激活上限 5 个
2. 技能总 token 预算 5000 tokens
3. rules 不注入生成，只注入审计层（零 token 成本）
4. 冲突检查：同分类同注入点不同时激活
5. 作用域覆盖：同名技能 小说级 > 用户级 > 内置级

## 5. 技能制造流程（五步）

**① 技能定义向导**：用户自然语言描述 → 子系统 Agent 生成 YAML 草稿 → 用户确认/修改
**② 格式验证**：必填字段（id/name/category/trigger/content/injection_points）、枚举值、token 预算
**③ 质量门禁**：L1 语法合规 → L2 功能正确 → L3 结构完整 → L4 语义深度（不与宪法/反AI味冲突）→ L5 元认知（规则不自相矛盾）
**④ 沙箱试运行**：用预置样例章节测效果（`13`），对比有/无技能质量差值 ≤5 分通过
**⑤ 用户确认入库**：Agent 综合质检+沙箱结果给建议；用户决定；入库时计算冲突矩阵

**技能制造 Agent 只给建议，不决策。所有写库操作必须由用户显式确认。**

## 6. 冲突矩阵

入库时预计算所有技能对语义冲突度。

```json
{
  "version": "1.0",
  "updated_at": "...",
  "threshold": 0.7,
  "pairs": [
    {
      "skill_a": "skill_pacing_control",
      "skill_b": "skill_slow_pace",
      "conflict_score": 0.82, "level": "high",
      "reason": "两技能在句长维度方向相反（短句 vs 长句）"
    }
  ]
}
```

**冲突度计算**：方向性冲突率×0.6 + 语义向量距离×0.4。≥0.7→high(不可同时)；0.4-0.7→medium(建议不同时)；<0.4→low(可同时)。

## 7. 预置技能清单（建议）

| 技能 | category | trigger |
|------|----------|---------|
| 节奏控制 | pacing_control | auto(动作/紧张场景) |
| 感官沉浸 | narrative_technique | always |
| 对话差异化 | dialogue_technique | always |
| 环境暗示法 | narrative_technique | manual（见 §2 示例） |

（扩展预置技能时遵循 §2 格式与 §4 冲突规则）
