# 11 · 质量报告 与 真相文件全量校验

> 定义幕/卷六维度质量报告，以及真相文件全量校验（错误传播截断点）。
> 版本：1.0 ｜ 依赖：`04`、`05`、`07` ｜ 相关：`10`(回滚)

---

## 1. 报告生成时机

- **幕间报告**：每写完一幕（通常 5-8 章）
- **卷间报告**：每写完一卷（通常 3-5 幕），在幕间基础上加全卷视角

## 2. 幕/卷文学质量报告（六维度）

**① 节奏曲线分析**
```
每章张力评分：第N章 X/10 — {描述}
曲线模式：rising/falling/wave/flat/monotone_decline
问题诊断：{单调递减/长期低谷/缺乏起伏}
节奏评分：{0-1}
```

**② 角色成长弧**
```
{角色}：成长弧完整度{0-1}；关键转折点；成长轨迹；问题诊断（停滞/突兀/断线）
```

**③ 伏笔回收率**
```
本幕/卷种下伏笔总数 N、已回收 M、回收率 M/N
未回收的关键伏笔（已搁置N章）、被放弃的伏笔、问题诊断（回收率过低/遗忘/回收集中）
```

**④ 文风漂移**
```
每章文风向量；漂移趋势（stable/gradual_drift/sudden_shift）；最大漂移度；问题诊断
```

**⑤ 读者预期管理**
```
未满足期待（已悬置N章）；戏剧性反讽利用率{0-1}；信息过载章节；期待满足度{0-1}
```

**⑥ 总体评估与建议**
```
总体文学质量评价 + 对下一幕/卷的建议（提升张力/推进弧光/回收伏笔/利用反讽）N 条
```

## 3. 真相文件全量校验（错误传播截断点）

章后管线-B 若更新错误，会通过真相文件**跨章传播**——后续章节都基于错误状态创作。单章审计无法发现，故每幕结束执行全量跨文件一致性校验。

### 3.1 校验范围

| 维度 | 校验 | 涉及文件 |
|------|------|---------|
| 角色认知边界一致 | knows/unknown/partial 与剧情矛盾 | 人物卡 × 摘要 |
| 关系网络闭环 | 是否有"凭空出现"的关系变化 | 关系卡 × 摘要 |
| 势力归属一致 | 叛逃角色是否仍归原势力 | 势力卡 × 人物卡 |
| 地理状态一致 | 被毁地点是否被写回原状态 | 地理卡 × 摘要 |
| 时间线无矛盾 | 多线冲突/角色分身/旅行时间 | 时间追踪 × 地理卡 × 摘要 |
| 伏笔状态一致 | convergence_point 与正文、resolved 是否被重引 | 伏笔 × 摘要 |
| 语义偷换一致 | 种子词当前阶段合法使用 | 伏笔 × 摘要 |
| 揭示链一致 | 依赖顺序、非揭示节点泄露 | 伏笔 × 大纲 × 摘要 |

> 涉及 `05` fact 时效窗口时，只对 `active` 事实基准校验；superseded 项不参与"当前一致性"判断（它们记录历史正确性）。

### 3.2 校验流程

```
幕完结
  ├─ ① 确定性校验（零 LLM）：时间线排序/旅行矩阵/伏笔状态机/概念演化阶段/揭示链DAG/种子词频率/关系图谱闭环/势力成员交叉/地理状态时间线
  ├─ ② LLM 语义校验（确定性标记问题 + 抽检关键维）：认知边界/关系合理性/伏笔合规/语义偷换/揭示完整性
  └─ ③ 输出校验报告：Blocker 必须修复后才能继续下一幕；Major 标记技术债务通知用户；Minor 记录下幕回顾
```

### 3.3 与回滚联动

公共发现 Blocker/Major 跨章传播错误时，走 `10` 的定点回滚定位并恢复到错误引入前的 checkpoint，再继续。这使"校验—定位—回滚—重写"形成闭环。
