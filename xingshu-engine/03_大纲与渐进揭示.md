# 03 · 大纲与渐进揭示

> 定义四层大纲系统与 reveal_density 渐进放行机制。
> 版本：1.0 ｜ 依赖：`01` ｜ 相关：`06`(伏笔与设定)、`08`(提示词)

---

## 1. 四层结构

大纲分四层，高层只给方向，底层才给具体内容。每层有 `reveal_density`（0.0-1.0）控制该层揭示给 LLM 的信息密度。

| 层级 | 内容 | 揭示密度 | 说明 |
|------|------|---------|------|
| 卷纲 | 主题方向、核心冲突、伏笔清单 | 低（0.2-0.3） | 只给方向，不剧透 |
| 幕纲 | 幕级剧情线、角色弧光阶段 | 中（0.4-0.5） | 给框架，留空间 |
| 章纲 | 章节场景、POV、关键事件 | 中高（0.6-0.7） | 给结构，定骨架 |
| 场景纲 | 具体动作、对话要点、情感节拍 | 高（0.8-1.0） | 给细节，定血肉 |

## 2. 各层格式

### 卷纲
```markdown
# 卷纲：{卷名}
## 主题方向 {一句话}
## 核心冲突 {主要矛盾}
## 角色弧光阶段 {角色：起点 → 目标}
## 伏笔清单 {[伏笔ID] 内容 → 目标章节}
## 隐藏设定揭示计划 {章节：揭示碎片}
## reveal_density: 0.3
```

### 幕纲
```markdown
# 幕纲：第{卷}卷 第{幕}幕 — {幕名}
## 幕级剧情线 {3-5句话}
## 角色弧光阶段 {起点 → 终点；关键转折：章 + 事件}
## 本幕涉及势力 {势力：行动目标}
## 本幕伏笔操作 {[ID]：planted→progressing 等}
## 张力曲线设计 {开头/发展/高潮/收束}
## 与卷纲的对齐 {推进的核心冲突 + 主题深化}
## reveal_density: 0.5
```

### 章纲（六维度）
```markdown
# 章纲：第{卷}卷 第{幕}幕 第{章}章 — {章名}
## 六维度章纲
### 梗概 {一句话}
### 角色行为 {角色：行为和动机}
### 场景氛围 {压抑/紧张/温馨}
### 核心冲突 {本章矛盾}
### 叙事目标 {在整体叙事中达成什么}
### 章节类型 {战斗/对话/探索/日常/转折/文艺段落}
## POV 配置 {单视角或多视角 + 认知边界过滤}
## 节拍分解（Scene & Sequel）{Scene:目标→冲突→后果；Sequel:情绪→两难→新目标}
## 本章伏笔操作 {植入/推进/揭示}
## 本章设定揭示 {按 reveal_density 允许的范围}
## 概念播种指令（若有）{种子词 + 当前阶段 + 使用方式}
## 字数目标 {目标字数}
## reveal_density: 0.7
```

### 场景纲
```markdown
# 场景纲：第{章}章 场景{No} — {场景名}
## 场景信息 {地点/地理ID、时间、在场角色、POV}
## 场景目标 {叙事目的}
## 具体动作 {角色：动作}
## 对话要点 {A→B：对话核心，不写台词}
## 情感节拍 {节拍：起始 → 触发 → 结束}
## 感官描写要点 {视觉/听觉/触觉嗅觉味觉（至少一非常规）}
## 场景出口 {结束状态 + 衔接}
## reveal_density: 0.9
```

## 3. reveal_density 的处理规则

- 只注入当前章节密度允许的设定；未达到密度的隐藏设定不进生成上下文（防提前剧透，见 `06`）。
- 卷纲 → 幕 → 章逐层过滤，低层不得越过高层设置。

## 4. 渐进揭示与子任务拆解

「精华借鉴」（LongWriter 的 AgentWrite 子任务拆解 + NovelForge 的 Planner→场景计划）：
- 去往生成器前，把"章纲 + 节拍分解"进一步拆为**最小可执行场景单元**，每个单元带清晰目标、开端与出口；
- 正文生成按场景单元逐个产出，而不是一次整章长文本；
- 节拍分解即"目录"微结构；每个节拍对应 1 个 unmoral 单元，降低单轮超长生成导致的质量崩塌。
